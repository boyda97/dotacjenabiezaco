# Dotacje na Bieżąco

Serwis [dotacjenabiezaco.pl](https://dotacjenabiezaco.pl): wyszukiwarka dotacji dopasowanych do firmy
(oraz do osób, które dopiero zakładają działalność), w subskrypcji miesięcznej z codziennymi
aktualizacjami albo z jednorazowym dostępem tygodniowym.

| Katalog | Co zawiera |
|---|---|
| `silnik/` | Pobieranie naborów ze źródeł i dopasowanie ich do profilu firmy (Python) |
